### 自動返信メールの設定方法
「MW WP Form」は、WordPressでお問い合わせフォームを作成するプラグインで、自動返信メールを設定することで、フォーム送信後にユーザーへ確認メールを自動送信できます。これにより、ユーザーはフォームが正しく送信されたことを確認でき、信頼性が高まります。

#### 手順
1. **フォーム作成**:
   - WordPress管理画面で「MW WP Form」→「新規追加」をクリック。
   - フォームのタイトルを入力し、フォームタグジェネレーターで必要項目（例：メールアドレス、名前など）を追加。
   - メールアドレス項目の`name`属性（例：`mail`）をメモしておく。

2. **自動返信メール設定**:
   - フォーム編集画面の右側サイドバーにある「自動返信メール設定」を開く。
   - **送信先（To）**：ユーザーのメールアドレスを指定。フォームで設定したメールアドレスの`name`属性（例：`{mail}`）を入力。
   - **件名**：例「お問い合わせありがとうございます」。
   - **送信元（From）**：サイトのメールアドレス（例：`info@yourdomain.com`）を入力。スパム判定を避けるため、ドメイン一致のアドレス推奨。
   - **送信者名**：サイト名や会社名（例：`このは屋`）。
   - **本文**：ユーザーが入力した内容を反映可能。例：`{name}様、お問い合わせありがとうございます。以下の内容で受付ました。` のように`{name}`でフォーム入力値を挿入。
   - **Reply-to**：返信先アドレスとしてサイト管理者のメールアドレスを設定（例：`info@yourdomain.com`）。

3. **管理者宛メール設定**:
   - 同様に「管理者宛メール設定」で、問い合わせ内容を管理者へ通知するメールを設定。
   - 送信先は管理者のメールアドレス（例：`admin@yourdomain.com`）。

4. **フォーム設置**:
   - フォームのショートコード（例：`[mwform_formkey key="xxx"]`）をコピー。
   - お問い合わせ用固定ページを作成し、ショートコードを貼り付け公開。

5. **動作確認**:
   - フォームからテスト送信を行い、自動返信メールがユーザー宛に、管理者宛メールが正しく届くか確認。
   - 迷惑メールフォルダやスパム判定もチェック。

#### 注意点
- **メール不着問題**：メールが届かない場合、サーバーのSMTP設定やドメイン認証（DKIM、SPF、DMARC）が原因の可能性。プラグイン「WP Mail SMTP」を導入し、送信元アドレスをサイトのドメインに一致させると改善する場合が多い。
- **開発終了**：MW WP Formは2023年9月に開発終了が発表済み。新規導入は推奨されず、保守は脆弱性対応のみ。代替として「Contact Form 7」や「Tayori」が提案されています。
- **カスタマイズ**：条件分岐や特定項目の表示変更は、フィルターフック（例：`mwform_auto_mail_mw-wp-form-xxx`）で対応可能。例：
  ```php
  function my_mail($Mail, $values, $Data) {
      if ($Data->get('category') == '質問') {
          $Mail->body = "ご質問ありがとうございます！";
      }
      return $Mail;
  }
  add_filter('mwform_auto_mail_mw-wp-form-xxx', 'my_mail', 10, 3);
  ```
  ※`xxx`はフォームの識別子に置き換える。

#### 「このは屋」のポイント
「このは屋」の記事では、自動返信メールの重要性を強調し、ユーザーの不安解消（「情報が送れたか心配」）を防ぐと述べています。設定は初心者でも可能ですが、以下のサンプルを参考に進めると良いでしょう：
- **サンプル本文**：`{name}様、この度はお問い合わせありがとうございます。内容を確認後、担当者よりご連絡いたします。`
- 設定画面で各フィールドの`name`属性を`{}`で囲んで本文に挿入。
