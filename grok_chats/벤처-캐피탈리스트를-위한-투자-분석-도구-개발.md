2. **사업 현황 정리**: 어떤 정보를, 어느 수준으로 요약할지, 출처를 어디서 가져올지 감이 없음

- **데이터 소스 제안**:
  - **네이버 증권**: 주가, 시총, PER 등 실시간 데이터 크롤링 가능 (API 없으므로 웹 스크래핑 필요)

  - **사업 현황**: DART 공시 자료(사업보고서)나 네이버 증권의 기업 개요 활용
- **기술 스택 제안**:
  - 프론트엔드: HTML/CSS/JavaScript (React나 Vue.js로 간단히 구현 가능)
  - 백엔드: Python (Flask나 FastAPI로 웹 서버 구축)
  - 데이터 크롤링: Python 라이브러리 (BeautifulSoup, Selenium 등)

#### 2. 장기 목표 상세화

- **3개년 재무제표**:

3. 웹페이지에 카드 형태로 데이터 표시 + Chart.js로 2년 주가 그래프 렌더링
4. 검색 기록에 "삼성전자" 추가 (클릭 시 동일 데이터 재표시)
5. 나중에 수정 시 `fetch_data.py`만 열어서 소스 추가/변경

---

### 의견
추가하신 요구사항(영업이익, 검색 기록, 주가 그래프)은 단기 목표에 충분히 포함 가능하고, 구현 난이도도 초보자가 AI 도움으로 해볼 만한 수준이에요. 특히 Chart.js는 그래픽 초보자에게도 접근성이 좋아 추천드립니다. 코딩이 익숙하지 않다면, 제가 특정 기능(예: 주가 크롤링, 그래프 그리기)의 샘플 코드를 제공할 수도 있어요.

이제 PRD로 넘어가실 건지, 아니면 특정 부분(예: 크롤링, 그래프)에 대해 더 구체적으로 알고 싶으신지 말씀해 주세요! 어떻게 생각하시나요?

```
# VC Quick Analyzer PRD

## 1. 개요
### 제품 이름
VC Quick Analyzer

### 목적
벤처 캐피탈리스트가 투자 분석을 효율적으로 수행할 수 있도록, 국내 상장 기업의 주요 투자 지표와 주가 흐름을 빠르게 확인하고 검색 기록을 관리하며, 장기적으로 해외 시장 데이터와 보고서 출력 기능을 제공하는 웹 기반 도구.

### 타겟 사용자
- 벤처 캐피탈리스트
- 투자 분석가
- 빠르고 직관적인 기업 데이터 접근을 원하는 개인 투자자

### 배경
투자 분석 시 Peer Group 데이터를 검색하는 과정이 번거롭고 시간이 오래 걸려, 이를 자동화하고 한눈에 확인할 수 있는 도구의 필요성 대두.

---

## 2. 단기 목표 (MVP)

### 2.1 기능 요약
- **입력**: 회사명 검색
- **출력**: 
  - 주요 지표: 주가, 시가총액, 매출, 영업이익, 이익, PSR, PER
  - 주가 그래프: 최근 2년 주가 데이터를 선 그래프 형태로 시각화
  - 검색 기록: 검색한 회사 데이터 누적 리스트 제공 (클릭 시 상세 정보 재표시)
- **형태**: 웹페이지

### 2.2 세부 요구사항

#### 입력
- **검색창**: 텍스트 입력 필드와 검색 버튼 제공
- **자동완성**: 회사명 일부 입력 시 관련 회사 리스트 제안 (옵션)

#### 출력
- **데이터 카드**:
  - 주가 (현재가)
  - 시가총액
  - 매출 (최신 연간)
  - 영업이익 (최신 연간)
  - 이익 (순이익, 최신 연간)
  - PSR (Price to Sales Ratio)
  - PER (Price to Earnings Ratio)
  - UI: 카드 형태로 깔끔하게 한 페이지에 표시
- **주가 그래프**:
  - 기간: 최근 2년
  - 형태: 선 그래프 (x축: 날짜, y축: 주가)
  - 도구: Chart.js 활용
- **검색 기록**:
  - 위치: 페이지 하단 또는 사이드바
  - 형태: 회사명 리스트 (클릭 시 해당 데이터 카드 및 그래프 재표시)
  - 저장: SQLite 또는 JSON 파일로 간단히 구현

#### 데이터 소스
- **네이버 증권**: 주가, 시가총액, PSR, PER, 2년 주가 데이터 (웹 크롤링)
- **DART**: 매출, 영업이익, 이익 (Open DART API 활용)

#### 기술 스택
- **프론트엔드**: HTML/CSS/JavaScript (React 또는 Vanilla JS)
- **백엔드**: Python (Flask)
- **데이터 크롤링**: Python (BeautifulSoup, requests)
- **그래프**: Chart.js
- **데이터 저장**: SQLite 또는 JSON

### 2.3 구현 고려사항
- **초보자 친화성**:
  - 코드 모듈화 (데이터 가져오기, UI, 그래프, 검색 기록 별도 함수)
  - 주석 상세 작성
- **수정 용이성**: 데이터 소스나 지표 추가 시 쉽게 확장 가능하도록 구조화

---

## 3. 장기 목표

### 3.1 기능 요약
- 해외 주식 데이터 지원
- 3개년 재무제표 출력
- DOCX 파일로 표 내보내기

### 3.2 세부 요구사항

#### 해외 주식 지원
- **데이터 소스**: Yahoo Finance (API 또는 크롤링)
- **추가 기능**: 환율 변환 (KRW/USD 등)

#### 3개년 재무제표
- **항목**: 매출, 영업이익, 순이익, 자산, 부채 등
- **소스**: DART (국내), Yahoo Finance (해외)
- **출력**: 데이터 카드에 연도별 탭 추가

#### DOCX 출력
- **형태**: 주요 지표와 재무제표를 표로 정리
- **도구**: Python (python-docx)
- **UI**: "보고서 다운로드" 버튼으로 DOCX 파일 생성 및 다운로드

### 3.3 확장 가능성
- 관심 기업 포트폴리오 관리
- 경쟁사 비교 분석
- 업종 평균 데이터 제공

## 4. 개발 우선순위
1. **MVP 구현**:
   - 네이버 증권 크롤링으로 주가, 시총, PSR, PER 표시
```
