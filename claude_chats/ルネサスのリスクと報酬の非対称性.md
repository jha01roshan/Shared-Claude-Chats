# ルネサス問題：リスク配分と報酬配分の非対称性分析

---

## 1. 論点の整理

**核心は一つ：同じ経営環境の中で、痛みと利益は誰に向かったか。**

整理すべき論点は以下の三層構造で捉えられる。

**第一層：経営判断の問題**
- Altium買収のリスク評価は十分だったか
- 市況軟化を認識していたなら、なぜその前提で計画が立てられなかったか
- 認識していなかったなら、それはリスク管理の問題ではないか

**第二層：リスク転嫁の問題**
- 買収後の財務負担を吸収するコストを誰が負ったか
- 「グローバルな機動的人事」という言語化によって、経営責任の所在がどう処理されたか

**第三層：報酬統治の問題**
- 人員削減・昇給延期が利益改善→株価→TSR連動報酬という経路で経営陣に還流する構造がないか
- 報酬委員会の独立性は「決定への不参加」だけで担保されるのか

---

## 2. 会社側の説明が成立する可能性

公平を期すため、会社側の論理が一定程度成立し得るシナリオを示す。

**「グローバル移行論」の成立条件**
日本型メンバーシップ雇用からジョブ型・グローバル型への移行という文脈自体は、日本の大企業が広く直面している構造問題であり、その移行に際して人事施策が変化すること自体は否定できない。

**「財務的必要性ではない」論の成立条件**
仮に人員施策の決定がAltium買収の財務的影響を織り込む以前に戦略的に設計されていたなら、「コスト削減が至上命題ではない」という説明は形式的には成り立つ。

**報酬委員会独立性の成立条件**
CEOが最終決定に参加しない形式的プロセスが整備されており、外部取締役が実質的に報酬水準・KPI設計を主導していたなら、独立性は一応担保される。

しかし、以下に示すように、これらはいずれも「成立条件」が非常に厳格であり、現状の開示内容では検証困難である点が問題である。

---

## 3. 会社側の説明が苦しくなるポイント

**矛盾①：市況軟化の扱いの二重性**

会社は「継続する市況の軟化を踏まえて」人員施策・投資精査を行ったと説明する一方、「財務的に厳しい状況に対応するコスト削減ではない」とも言う。しかし、市況軟化を根拠に挙げながら財務的必要性を否定するこの二文は、論理的に同居しにくい。市況軟化が根拠なら、財務的文脈は切り離せない。

**矛盾②：シリコンサイクルは「想定外」ではない**

半導体業界のシリコンサイクル・市況変動は、業界固有の構造的リスクとして数十年来知られている。「継続する市況の軟化」を理由に出すこと自体が、その変動を経営計画に十分織り込んでいなかった可能性を示唆する。

**矛盾③：Altium買収のタイミングと人員施策のタイミング**

Altium買収完了後の時系列において、定期昇給延期・人員施策が実施されているなら、買収後の財務負担との関係性を問われる余地がある。「関係がない」と言うためには、その独立性を説明する根拠が必要になる。

**矛盾④：株主還元・役員LTIの維持**

同じ期間に株主還元や役員LTI（RSU/PSU）が維持・実行されているなら、「財務的に厳しい状況に対応するものではない」という説明は、従業員側の処遇との対比において説得力を問われる。痛みが非対称に分配されているように見えるからである。

---

## 4. ガバナンス上の本丸

**本丸は「説明の非対称性」にある。**

コーポレートガバナンス・コードが求めるのは、取締役会による経営の監督と、ステークホルダーへの説明責任である。問われるべき点を列挙する。

**① 経営判断の事後的検証が開示されているか**

Altium買収が「市況軟化を認識した上での戦略的判断」だったなら、その後の市況軟化に対してどのような対応計画を持っていたか、事後的にどう評価したか、が投資家・ステークホルダーへ開示されるべきである。この検証過程が見えない場合、ガバナンスの透明性に疑問符がつく。

**② 人的資本リスクの取締役会レベルでの扱い**

人員施策・退職勧奨が「グローバル移行」として処理された場合、そのリスク（労使関係、法的リスク、人的資本の棄損、企業文化への影響）が取締役会レベルでどのように評価・監督されたかが問われる。

**③ コーポレートガバナンス・コード改訂前からの問題**

コード改訂（2021年）で人的資本開示や取締役会の多様性・独立性が強化されたが、報酬統治における利益相反管理の問題、説明責任の問題は改訂前から原則として存在する。「改訂後に対応した」という説明は、それ以前の問題を免責しない。

---

## 5. 役員報酬・報酬委員会の問題

**「決定に参加しない」は必要条件だが十分条件ではない。**

報酬統治の独立性に関して、最も見落とされがちな論点がここにある。

**ゲームのルール設計問題**

報酬委員会においてCEOが「自分の報酬の最終採決には参加しない」としても、以下の設計段階に関与しているなら、独立性は実質的に問われる。

- TSR連動のKPI設計において、M&Aや自己株取得がTSRに与える影響をどう扱うか
- PSU/RSU比率と評価期間の設定
- 参照企業群の選定（ベンチマーク企業を高報酬グループに偏らせれば水準が上がる）
- 人員削減・昇給延期の「コスト削減効果」を業績評価にどう反映するか、または反映しないか

**利益環流の構造的リスク**

人員削減・昇給延期 → 費用削減 → 営業利益改善 → EPS向上・株価押し上げ → TSR改善 → TSR連動LTI価値増大

このような経路が構造的に存在する場合、「人員削減で経営陣が報酬上の利益を得る」という外見上の問題が生じ得る。これは直ちに不正を意味しないが、報酬設計の説明責任として開示・説明が求められる事項である。

**「ハイブリッド型委員会関与」の問題**

形式的には外部取締役主導の報酬委員会であっても、CEOが情報提供・論点整理・資料作成の実質的主導権を持つ場合、「ゲームのルール」は事前に設定されてしまう。この構造的問題は、CEOが「CFO出身で財務指標に精通している」ケースで特に顕在化しやすい。

## 6. 「リストラ問題ではない」と言える理由

**リストラは現象であり、本質は資本配分とリスク配分の統治問題である。**

「リストラ問題」として見た場合、議論は「人を減らすことの是非」に収束し、企業の構造改革の文脈では一定程度正当化されやすい。しかし、この問題を「リストラ問題」として語ることは、むしろ問題の核心を見えにくくする。

**「リストラ問題ではない」と言える理由を三点に整理する。**

**理由①：リスク配分の問題**
同じ経営環境・同じ時間軸の中で、誰がリスクを負い、誰がリターンを受け取ったか。経営判断（M&A・財務戦略・投資計画）から生じたリスクが、なぜ従業員の雇用・賃金・離職理由に現れ、経営陣のLTIには現れにくい構造になっているか、という問いである。

**理由②：言語と実態の乖離の問題**
「グローバルな機動的人事」「将来投資」「ポジション削減」という言語化によって、経営責任の所在が希薄化されていないか。同じ事象が「退職勧奨」か「自己都合退職」か「ポジション廃止」かによって、人的資本データ上の見え方は大きく異なる。これは開示と実態の整合性の問題である。

**理由③：報酬統治の問題**
経営陣のLTI・PSU・RSUが、人員削減後の業績改善・株価上昇を通じて価値を持つ構造が存在する場合、「誰が痛みを負い、誰が利益を得たか」という非対称性は、単なる感情論ではなく、ガバナンスの設計問題として語られるべきである。

## 9. 名誉毀損・断定リスクを避けた表現への修正案

| 断定的表現（使用禁止） | 推奨表現 |
|---|---|
| 「役員報酬に横流しした」 | 「TSR連動報酬との構造的接続が問われる余地がある」 |
| 「意図的に隠した」 | 「開示の質的情報が不足しており、投資家・社会が正確に評価できる状態にあるか疑問が残る」 |
| 「違法な退職強要だ」 | 「プロセスの透明性と適法性について説明が求められる」 |
| 「報酬委員会は機能していない」 | 「形式的な独立性要件だけで実質的独立性が担保されるかは、別途検証が必要な論点である」 |
| 「Altiumのために切り捨てた」 | 「買収の財務的影響と人員施策の時系列的関係は、説明責任の観点から問いを立てる余地がある」 |
| 「経営責任を逃れた」 | 「経営判断に伴うリスクが、役員報酬評価においてどう扱われたかは開示上明確でない」 |
| 「糖衣構文で誤魔化した」 | 「使用された言語が実態との対応において、ステークホルダーの正確な理解を促進するものだったか問われ得る」 |

---

**総括：問いの立て方が批判の質を決める**

この問題を「リストラが悪い」という感情論で語ることは、会社側に「構造改革の必要性」という盾を与え、議論を終わらせる。しかし「同じ経営判断の中で、リスクと報酬はどこへ向かったか」という問いとして立てることで、開示・統治・報酬設計・言語使用の問題として永続的に問い続けられる構造になる。これが「リストラ問題ではない」と言うことの、戦略的・論理的意味である。
