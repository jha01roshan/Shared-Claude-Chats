**가격대**: 저가형(탈수 없음, 수동 급수) 30~80유로, 중가형(탈수 기능 포함, 급수 호스 연결) 80~180유로, 고급형(자동 급수+배수, 타이머) 150~400유로.

**실효성**: 한 달 20~25유로 세탁비 지출 기준, 18개월이면 총 360~450유로. 80~150유로대 기기면 1년 내 회수 가능. 단, 미니세탁기는 용량이 1.5~3.5kg으로 적어 이불·수건 같은 부피 큰 빨래는 못 돌리고, 탈수력도 일반 세탁기 대비 약함(원심력 낮아 옷이 많이 젖은 채로 나옴 → 건조 시간 김). 화장실 환경은 습도·온도 변화가 커서 내구성도 일반 가정용보다 떨어짐.

**구조상 핵심 조건**: 문 앞이 막혀 있으니 프론트로더는 무조건 제외, 탑로더(위에서 넣는 방식) 또는 펄세이터형만 고려 대상.

**추천 모델**:

1. **Klarstein Big Daddy / Soloclean 시리즈** — 탑로더, 3.5~5kg, 탈수 포함, 급배수 호스 연결 가능. 가격 130~180유로대. Amazon.de에서 구매 쉬움.

2. **CLEANmaxx Mini-Waschmaschine** (2~3.5kg) — 가격 80~120유로, 탈수 기능 있는 모델과 없는 모델 혼재하니 구매 전 스펙 확인 필요.

3. **Comfee 1.9kg 미니 세탁기** — 가격 100유로 안팎, 탑로더, 소형, 1인 가구 다회 후기 많음.

4. **TecTake / Sichler Mini-Waschmaschine** — 30~70유로대 최저가. 단, 탈수 없거나 약함, 배수 호스가 아예 없는 모델도 있어 직접 들어서 버려야 하는 경우 있음 → 화장실 변기/세면대 옆이면 그나마 편함.

**구매 전 체크할 것**:
- 정수압 급수 연결(festen Wasseranschluss) 가능한지 vs 수동으로 물 부어야 하는지 — 설치 환경에 배관 있다고 했으니 급수 연결형이 훨씬 편함.
- 배수 호스 길이와 화장실 배수구 위치/높이 (중력 배수면 호스가 배수구보다 높게 설치돼야 역류 안 함).
- 220V 콘센트 위치 — 화장실 콘센트는 누전차단기(FI-Schutzschalter) 필수, 독일 화장실 규정상 이미 있을 가능성 높음.
- 1.5kg 정도 용량은 너무 작아 실제론 일주일 빨래량을 못 감당하는 경우 많음 → 최소 3kg대 권장.

처분도 고려한다면 중고 거래(eBay Kleinanzeigen) 잘 되는 Klarstein·Comfee 같은 알려진 브랜드가 18개월 후 되팔기에도 유리.
