The standard language code for Simplified Chinese is **zh-Hans** — that's the ISO standard used by most platforms including Squarespace, Google, and web browsers. Traditional Chinese would be **zh-Hant**.

The typical URL convention for multilingual pages is one of two patterns:

**Subdirectory** — most common, cleanest for SEO:
- `/trust-before-returns` — English
- `/zh/trust-before-returns` — Chinese

Or with the full language code:
- `/zh-hans/trust-before-returns`

**Suffix** — simpler, used a lot on smaller sites:
- `/trust-before-returns` — English
- `/trust-before-returns-zh` — Chinese

For Squarespace specifically, the platform doesn't have native multilingual routing built in — it treats each page as its own URL. So the cleanest approach there is the suffix convention:

- `/trust-before-returns`
- `/trust-before-returns-zh`

That way both pages live at the same level, are clearly related by the slug, and a reader who shares either link can see from the URL which version they're in.
